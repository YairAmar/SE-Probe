# External datasets

The SE-Probe **demo** notebooks (02–05, plus the figure cells of 01 and 06) read precomputed CKA tables from `results_demo/` and **do not need any of the datasets below**. You only need them if you want to:

- recompute CKA from raw audio,
- run end-to-end inference in notebooks 01 / 06 on new utterances, or
- regenerate `results_df/` from scratch.

Point the env vars below at local copies before running the relevant scripts. `se_probe.consts.set_paths(...)` accepts the same values programmatically (handy for tests / fixtures).

| Env var | Dataset | Used for | Download |
|---|---|---|---|
| `SEPROBE_VCTK_DIR` | VCTK-Corpus (clean speech, test speakers) | Source of clean utterances. Loader downsamples 48 → 16 kHz on the fly. | https://datashare.ed.ac.uk/handle/10283/2950 |
| `SEPROBE_DEMAND_DIR` | DEMAND multi-channel noise database | Additive noise for SNR sweeps. | https://zenodo.org/records/1227121 |
| `SEPROBE_AIR_RIR_DIR` | Aachen Impulse Response (AIR) database | Room impulse responses for the reverb experiments (notebook 06). | https://www.iks.rwth-aachen.de/forschung/tools-downloads/databases/aachen-impulse-response-database/ |

## Expected layouts

```
$SEPROBE_VCTK_DIR/
    p<speaker_id>/
        p<speaker_id>_<utt_id>.wav   # 48 kHz mono
$SEPROBE_DEMAND_DIR/
    <NOISE_NAME>.wav                 # e.g. TBUS.wav, SPSQUARE.wav (16 kHz mono)
$SEPROBE_AIR_RIR_DIR/
    air_binaural_<room>_<config>.mat # MATLAB struct with field h_air (48 kHz)
```

The exact speaker / noise / room subsets used in the paper are listed in `se_probe/consts.py` (`TEST_SPEAKERS`, `TEST_NOISES`, `AIR_TEST_ROOMS`).

## Precomputed CKA tables

The full `results_df/` (~3.1 GB of parquets, every model × every SNR × every noise × every utterance × every layer) is hosted on HuggingFace. Pull it with:

```bash
python scripts/setup.py --full-data
```

This downloads from the HuggingFace dataset named by `SEPROBE_HF_DATA` (default `yairamr/SE-Probe-data`).

## Quick sanity check

If you set `SEPROBE_VCTK_DIR` and `SEPROBE_DEMAND_DIR` and want to verify they work without launching a notebook:

```python
from se_probe.io import load_clean_wavs
from se_probe.data_generation import load_demand_noise
print(len(load_clean_wavs()), "clean utterances")
print(load_demand_noise("TBUS").shape, "TBUS noise samples")
```


## The 824-utterance sweeps of the TASLP revision

The journal version of the paper is computed on the full VoiceBank-DEMAND test split (824 utterances, speakers p232 and p257) rather than the 780 VCTK utterances of the preprint. The reduced tables behind every published number ship in `results_tables/` (see its README and `MANIFEST.csv`). The raw per-utterance artifacts are several GB and live on the project cluster; `scripts/README.md` lists the driver that regenerates each one from the public inputs.

| Artifact | Grid | Rows | Regenerated by |
|---|---|---|---|
| noise sweep, three models | 824 utts x 41 SNRs x 18 DEMAND noises | 96.5 M (one parquet per model/noise/SNR) | `scripts/run_snr_grid.py` |
| reverberation sweep, six arms | 824 utts x 13 target C50 x 5-of-88 AIR RIRs, pretrained and fine-tuned MUSE / MP-SENet / Demucs | 3.9 M per MUSE arm | `scripts/run_reverb_grid.py` |
| random-initialisation control | 824 x 41 x 5 test noises x 3 seeds | 12.2 M | `scripts/run_random_init_grid.py` |
| emergence over fine-tuning | 824 x 41 x 5 at epochs 1, 3, 5, 7, 9, 10, 12, 24, 36, 48 | 40.5 M | `scripts/run_emergence_grid.py` |
| per-mixture quality metrics | 824 x 41 x 5 x 3 models, PESQ / STOI / SI-SDR / DNSMOS | 0.5 M | `scripts/run_perceptual_grid.py` + `join_perceptual.py` |
| diffusion centroids | 24 MUSE layers x 41 SNRs x 5 noises | 4,920 centroids | `scripts/run_diffusion_centroids.py` + `build_diffusion_psi.py` |

The clean source is the VoiceBank-DEMAND 16 kHz test set (`JacobLinCool/VoiceBank-DEMAND-16k` on HuggingFace, or the `clean_test` wav folder); the 18 DEMAND recordings include SCAFE, which DEMAND does not publish at 16 kHz and which is resampled from the 48 kHz release.

The earlier 780-utterance tables of v0.1.x remain on HuggingFace (`yairamr/SE-Probe-data`); the preprint-era `snr/cka_snr_mpsenet_*.parquet` files there come from a superseded MP-SENet pipeline, the corrected one is `snr_v2/cka_snr_mpsenet_v2.parquet`.
